# Student CRUD API

A simple REST API built using Spring Boot to perform CRUD (Create, Read, Update, Delete) operations on Student data.

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Maven
- REST API

## 📌 Features

- Get All Students
- Get Student By ID
- Add Student
- Update Student
- Delete Student

## 📂 Project Structure

src
├── controller
├── service
├── repository
└── model

## 📦 Data Storage

Current Version:
- ArrayList (In-Memory Storage)

Upcoming Version:
- Spring Data JPA
- Hibernate
- MySQL

## 🛠️ API Endpoints

GET /students

GET /students/{id}

POST /students

PUT /students/{id}

DELETE /students/{id}
